Short Biography

I'm a Grade 10 student who enjoys mathematics and computer programming. I love using technology to solve everyday problems, especially those that students face in school. That's why I created **Math Hub**—a website designed to help students quickly find formulas, check calculations, and make learning math more convenient.

Skills Learned

HTML5 CSS3 / Responsive Design JavaScript (DOM & Functions) Form Validation Git & GitHub GitHub Pages Deployment UI / UX Basics

Reflection

I created this website using HTML, CSS, and JavaScript. This project improved my programming skills and taught me how to publish websites using GitHub. Building each calculator helped me understand the formulas better than just memorizing them, and debugging my own JavaScript taught me patience and attention to detail. I'm proud that Math Hub is something my classmates can actually use to check their homework.
